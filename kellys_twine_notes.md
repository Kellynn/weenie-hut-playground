Potential Issues with Source Control & Collaboration
- Twine games are saved as one giant HTML file, which makes viewing diffs difficult
- A way to make this easier is to use TweeGo, which changes the files to plain text and can break things down into multiple files
- If you want to use the Twine editor though, you will have to compile / decompile every time you're loading new code (which sounds like a potential pain for less technical folks)
